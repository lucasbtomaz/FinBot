# FinBot v0.0.1
Primeira distribuição desktop para Windows x64.
Inclui contas e cartões, parcelas e recorrências, recebíveis, projeção de caixa, investimentos com histórico, organização para IR e comprovantes opcionais.
Cada instalação inicia sem dados demonstrativos ou dados de outros usuários.
Requer Edge WebView2 Runtime. Extraia o ZIP inteiro antes de abrir FinBot.exe.
Limitações: sem assinatura digital, sem instalador, sem sincronização, sem criptografia própria e sem envio de declaração de IR.
As verificações SHA-256 acompanham o pacote. A publicação da release é manual.
